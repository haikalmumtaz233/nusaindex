# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on the Security tab of this repository, or open a draft advisory directly at https://github.com/haikalmumtaz233/nusaindex/security/advisories/new. Do not open a public issue.

Useful reports include the affected version, the module or tool (Go package, npm subpath, CLI, or MCP server), and the smallest input that shows the problem. Use values from the `fake` generator, never real personal data.

## Disclosure Process

- You can expect an initial response within 7 days.
- Confirmed vulnerabilities are fixed in a patch release, normally within 30 days of confirmation.
- The advisory is published once the fix is released, crediting the reporter unless you prefer otherwise.
- Please keep the details private until the advisory is published or 90 days have passed since your report, whichever comes first.
