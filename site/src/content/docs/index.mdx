## Aman dari awal

- **Offline.** Tanpa request jaringan, log, atau telemetri. Input tidak pernah keluar dari aplikasimu.
- **Bisa ditelusuri.** Setiap dataset mencatat regulasi dan dokumen sumbernya di [`data/manifest.json`](/project/data-sources/).
- **Tidak resmi.** Tidak berafiliasi dengan Dukcapil, DJP, Komdigi, Polri, Bank Indonesia, atau instansi pemerintah mana pun. Valid artinya **strukturnya benar**, bukan berarti nomornya asli atau milik seseorang.
