## Fungsi

| Go                       | TypeScript                | Hasil                                                             |
| ------------------------ | ------------------------- | ----------------------------------------------------------------- |
| `rupiah.Format(a, opts)` | `rupiah.format(n, opts?)` | `Rp1.500.000,50`                                                  |
| `rupiah.Parse(s)`        | `rupiah.parse(s)`         | Nominal (Go: `Amount` dalam sen, TypeScript: number dalam rupiah) |
| `rupiah.Valid(s)`        | `rupiah.isValid(s)`       | Apakah `s` bisa di-parse                                          |
| `rupiah.Terbilang(a)`    | `rupiah.terbilang(n)`     | `satu juta lima ratus ribu rupiah lima puluh sen`                 |

## Nominal

- **Go** memakai `rupiah.Amount`, `int64` dalam sen, sehingga aritmetika selalu tepat: `150_000 * rupiah.Rupiah + 50 * rupiah.Sen`.
- **TypeScript** memakai `number` dalam rupiah. Nominal dengan sen dibatasi di bawah 10 triliun (`MAX_SEN_AMOUNT`) agar tetap tepat; nominal bulat sampai 999 triliun (`MAX_AMOUNT`).

## Opsi format

| Go `Options` | TypeScript      | Efek                                   |
| ------------ | --------------- | -------------------------------------- |
| `Decimals`   | `decimals`      | Selalu tampilkan sen: `Rp2.000.000,00` |
| `OmitSymbol` | `symbol: false` | Tanpa awalan `Rp`                      |

Tanpa `Decimals`, sen hanya ditampilkan jika tidak nol. Nominal negatif ditulis `-Rp1.000`.

## Parsing

`Parse` menerima cara orang Indonesia menulis nominal: awalan `Rp`, `Rp.`, atau `IDR` (opsional), titik sebagai pemisah ribuan, koma sebelum sen, dan akhiran `,-`. `Rp 25.000,-`, `IDR 1.500.000,50`, dan `25000` semuanya bisa di-parse. Input dibatasi 64 karakter.

## Error

`length`, `charset`, `format` (pemisah salah tempat, lebih dari dua digit sen), `range` (melebihi nominal yang didukung).
