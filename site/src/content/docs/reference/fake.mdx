:::danger[Hanya untuk pengujian]
Nomor yang dihasilkan strukturnya benar dan bisa saja milik orang sungguhan. Jangan pernah memakainya di luar test, demo, dan fixture, dan jangan pernah menyajikannya sebagai data asli.
:::

<Live tool="fake" />

Setiap generator menerima seed 32-bit (`uint32` di Go, bilangan bulat 0 sampai 4.294.967.295 di TypeScript). Seed dan opsi yang sama menghasilkan nilai yang sama di Go dan TypeScript, sehingga fixture bisa dipakai bersama oleh backend Go dan frontend TypeScript.

## Fungsi

| Go                       | TypeScript                    | Opsi                             |
| ------------------------ | ----------------------------- | -------------------------------- |
| `fake.NIK(seed, opts)`   | `await fake.nik(seed, opts?)` | `region`, `birthDate`, `sex`     |
| `fake.NPWP(seed)`        | `fake.npwp(seed)`             |                                  |
| `fake.Phone(seed)`       | `fake.phone(seed)`            |                                  |
| `fake.NIP(seed, opts)`   | `fake.nip(seed, opts?)`       | `birthDate`, `sex`               |
| `fake.NISN(seed)`        | `fake.nisn(seed)`             |                                  |
| `fake.Plate(seed, opts)` | `fake.plate(seed, opts?)`     | `region` (kode plat seperti `B`) |

- NIK memakai kode kecamatan yang nyata. `region` bisa mengunci ke provinsi (`31`), kabupaten/kota (`31.71`), atau kecamatan (`31.71.01`); `birthDate` (`YYYY-MM-DD`) dan `sex` (`male` atau `female`) menentukan tanggal dan tambahan +40 untuk perempuan.
- Di TypeScript `fake` hanya diekspor dari `nusaindex/fake`, tidak dari root, sehingga tidak ikut ke bundle produksi tanpa sengaja. `fake.nik` bersifat async karena data kecamatan dimuat per provinsi.
- Go mengembalikan `string` untuk generator tanpa opsi; TypeScript mengembalikan `Result` untuk semuanya, yang gagal dengan `options` jika seed tidak valid.

Perubahan data wilayah bisa mengubah NIK yang dihasilkan untuk seed yang sama. Kunci versi NusaIndex di test yang membandingkan nilai persis.

## Error

`options`, `date`, `region`.
