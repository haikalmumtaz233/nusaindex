Menerima `08…`, `628…`, `+62 8…`, dan telepon tetap dengan kode area seperti `(021) 3456 789`. Prefix seluler dan kode area telepon tetap mengikuti Permenkominfo 14/2018.

## Fungsi

| Go                      | TypeScript              | Hasil                                             |
| ----------------------- | ----------------------- | ------------------------------------------------- |
| `phone.Valid(s)`        | `phone.isValid(s)`      | Apakah `s` nomor Indonesia yang strukturnya benar |
| `phone.Parse(s)`        | `phone.parse(s)`        | Field di bawah                                    |
| `phone.Format(s)`       | `phone.format(s)`       | E.164, misalnya `+628595257171`                   |
| `phone.WhatsAppLink(s)` | `phone.whatsappLink(s)` | `https://wa.me/628595257171`                      |
| `phone.Mask(s)`         | `phone.mask(s)`         | `+62` dan 3 digit terakhir terlihat               |

Pemisah yang diterima: spasi, `-`, `.`, `(`, dan `)`.

## Field hasil parse

| Field (JSON) | Contoh          | Catatan                                                                               |
| ------------ | --------------- | ------------------------------------------------------------------------------------- |
| `e164`       | `+628595257171` |                                                                                       |
| `national`   | `08595257171`   |                                                                                       |
| `type`       | `mobile`        | `mobile` atau `fixed`                                                                 |
| `prefix`     | `0859`          | Hanya seluler                                                                         |
| `brand`      | `XL`            | Hanya seluler: Telkomsel, IM3, Tri, XL, AXIS, atau Smartfren                          |
| `operator`   | `XLSmart`       | Hanya seluler: Telkomsel, Indosat Ooredoo Hutchison, atau XLSmart                     |
| `areaCode`   | `021`           | Hanya telepon tetap; lihat [`region.ByAreaCode`](/reference/region/) untuk wilayahnya |

Nomor seluler punya 9 sampai 12 digit setelah `0` di depan; telepon tetap 8 sampai 11 digit termasuk kode area. Prefix yang dicabut atau tidak pernah dialokasikan, seperti `0827`, `0828`, dan `0879`, gagal dengan `prefix`.

## Error

`length`, `charset`, `country` (kode negara selain +62), `prefix`.
