Datanya dari SKB 3 Menteri tiap tahun beserta semua perubahannya, plus Keppres hari pemungutan suara. Cakupannya 2020 sampai 2027 dan bertambah setiap ada SKB baru.

## Fungsi

| Go                          | TypeScript                  | Hasil                                            |
| --------------------------- | --------------------------- | ------------------------------------------------ |
| `holiday.Years()`           | `holiday.years()`           | `{ from, to }`: tahun yang tercakup              |
| `holiday.InYear(year)`      | `holiday.inYear(year)`      | Semua entri dalam setahun, urut tanggal          |
| `holiday.Between(from, to)` | `holiday.between(from, to)` | Entri dalam rentang tanggal (inklusif)           |
| `holiday.On(date)`          | `holiday.on(date)`          | Entri pada satu tanggal (biasanya nol atau satu) |

Tanggal berupa string `YYYY-MM-DD`, bukan objek `Date`, jadi tidak bergeser gara-gara zona waktu.

## Field libur

| Field (JSON) | Contoh                    | Catatan                            |
| ------------ | ------------------------- | ---------------------------------- |
| `date`       | `2026-08-17`              |                                    |
| `kind`       | `national`                | `national` atau `collective_leave` |
| `name`       | `Proklamasi Kemerdekaan`  | Nama sesuai SKB                    |
| `nameEn`     | `Independence Day`        | Nama dalam bahasa Inggris          |
| `basis`      | `SKB 1497/2/5 Tahun 2025` | Dasar hukum entri tersebut         |

## Error

`date` (bukan tanggal `YYYY-MM-DD`), `range` (tahun tanpa data, atau `from` setelah `to`).
