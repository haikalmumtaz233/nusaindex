Hari kerja melewati akhir pekan, libur nasional, dan cuti bersama dari [`holiday`](/reference/holiday/). Cocok untuk tanggal gajian, SLA, dan jatuh tempo.

## Fungsi

| Go                              | TypeScript                       | Hasil                                                 |
| ------------------------------- | -------------------------------- | ----------------------------------------------------- |
| `workday.IsWorkday(date, opts)` | `workday.isWorkday(date, opts?)` | Apakah `date` hari kerja                              |
| `workday.Add(date, days, opts)` | `workday.add(date, days, opts?)` | Tanggal `days` hari kerja kemudian (negatif = mundur) |
| `workday.Count(from, to, opts)` | `workday.count(from, to, opts?)` | Jumlah hari kerja dari `from` sampai `to`, inklusif   |

## Opsi

| Go `Options`               | TypeScript                 | Default          |
| -------------------------- | -------------------------- | ---------------- |
| `Weekend []time.Weekday`   | `weekend: number[]`        | Sabtu dan Minggu |
| `CollectiveLeaveIsWorkday` | `collectiveLeaveIsWorkday` | `false`          |

Hari akhir pekan di TypeScript memakai `0` untuk Minggu sampai `6` untuk Sabtu, seperti `Date.getUTCDay()`. Enam hari kerja seminggu ditulis `[0]`.

Perhitungan cuma jalan di tahun yang punya data libur, supaya hasilnya tidak diam-diam salah. Tanggal di luar rentang itu gagal dengan `range`.

## Error

`date`, `range` (di luar tahun yang tercakup, atau `from` setelah `to`), `options` (hari akhir pekan tidak valid, atau semua hari dijadikan akhir pekan).
