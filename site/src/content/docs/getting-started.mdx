<Steps>

1. Pasang paketnya. Go 1.25 atau lebih baru hanya memakai standard library; TypeScript berjalan di Node.js 22.18 atau lebih baru, Bun, Deno, edge runtime, dan browser modern (hanya ESM).

   ```sh title="Go"
   go get github.com/haikalmumtaz233/nusaindex
   ```

   ```sh title="TypeScript"
   npm install nusaindex
   ```

2. Jalankan pengecekan pertama. Contoh ini dijalankan setiap build, di kedua bahasa, dan keluarannya harus sama.

   <Example name="quickstart" />

3. Import seperlunya. Setiap modul adalah paket Go (`github.com/haikalmumtaz233/nusaindex/<nama>`) dan subpath TypeScript (`nusaindex/<nama>`) tersendiri. `nusaindex/nik` menambah kurang dari 2 KB gzip ke bundle browser, dan data wilayah dimuat per provinsi.

</Steps>

## API sama, dua bahasa

| Operasi     | Go                          | TypeScript                  |
| ----------- | --------------------------- | --------------------------- |
| Cek cepat   | `Valid(s) bool`             | `isValid(s): boolean`       |
| Parse       | `Parse(s) (T, error)`       | `parse(s): Result<T>`       |
| Normalisasi | `Format(s) (string, error)` | `format(s): Result<string>` |
| Mask        | `Mask(s) string`            | `mask(s): string`           |

Nama mengikuti konvensi tiap bahasa (`WhatsAppLink`, `whatsappLink`). Test vector bersama dijalankan di kedua implementasi, jadi hasilnya identik. Di TypeScript, `fake`, `zod`, dan `valibot` hanya tersedia lewat subpath.

:::note[Data contoh]
Nomor di situs ini dibuat dengan generator [`fake`](/reference/fake/). Jangan pernah menempelkan data pribadi asli ke contoh, issue, atau chat AI.
:::
