## Install

<Tabs syncKey="language">
  <TabItem label="Go">
    Go 1.25 or later. The module has no dependencies outside the standard library.

    ```sh
    go get github.com/haikalmumtaz233/nusaindex
    ```

  </TabItem>
  <TabItem label="TypeScript">
    Node.js 22.18 or later, Bun, Deno, edge runtimes, or any modern browser. ESM only, zero runtime
    dependencies.

    ```sh
    npm install nusaindex
    ```

## First check

<Tabs syncKey="language">
  <TabItem label="Go">

```go
package main

import (
	"fmt"

	"github.com/haikalmumtaz233/nusaindex/nik"
)

func main() {
	parsed, err := nik.Parse("7502010706599583")
	if err != nil {
		fmt.Println("invalid:", err)
		return
	}
	fmt.Println(parsed.BirthDate, parsed.Sex)
}
```

  </TabItem>
  <TabItem label="TypeScript">

```ts
import * as nik from "nusaindex/nik";

const parsed = nik.parse("7502010706599583");
if (parsed.ok) {
  console.log(parsed.value.birthDate, parsed.value.sex);
} else {
  console.log("invalid:", parsed.error.code);
}
```

  </TabItem>
</Tabs>

## Imports

| Go package                                    | TypeScript                                          |
| --------------------------------------------- | --------------------------------------------------- |
| `github.com/haikalmumtaz233/nusaindex/<name>` | `nusaindex/<name>`, or a namespace from `nusaindex` |

Each module is a separate Go package and a separate TypeScript subpath, so you only ship what you import. Importing `nusaindex/nik` adds less than 2 KB gzip to a browser bundle; region data loads per province only when you call `region`.

`fake`, `zod` and `valibot` are subpath-only in TypeScript and are not part of the root `nusaindex` export.

## Same API, two languages

| Operation   | Go                          | TypeScript                  |
| ----------- | --------------------------- | --------------------------- |
| Quick check | `Valid(s) bool`             | `isValid(s): boolean`       |
| Parse       | `Parse(s) (T, error)`       | `parse(s): Result<T>`       |
| Normalize   | `Format(s) (string, error)` | `format(s): Result<string>` |
| Mask        | `Mask(s) string`            | `mask(s): string`           |

Names follow each language's conventions (`WhatsAppLink` and `whatsappLink`, `FromNIK` and `fromNik`). Results are identical: every function is covered by shared test vectors that run against both implementations.
