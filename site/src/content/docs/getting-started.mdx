<Steps>

1. Pasang paketnya. Versi Go butuh Go 1.25 ke atas dan cuma memakai standard library. Versi TypeScript jalan di Node.js 22.18 ke atas, Bun, Deno, edge runtime, dan browser modern.

   ```sh title="Go"
   go get github.com/haikalmumtaz233/nusaindex
   ```

   ```sh title="TypeScript"
   npm install nusaindex
   ```

2. Coba pengecekan pertama. Contoh ini ikut dijalankan setiap build di kedua bahasa, dan hasilnya harus sama.

   <Example name="quickstart" />

3. Import yang kamu perlu saja. Tiap modul punya paket Go (`github.com/haikalmumtaz233/nusaindex/<nama>`) dan subpath TypeScript (`nusaindex/<nama>`) sendiri. `nusaindex/nik` cuma menambah kurang dari 2 KB gzip ke bundle browser, dan data wilayah dimuat per provinsi.

</Steps>

## API sama, dua bahasa

| Operasi     | Go                          | TypeScript                  |
| ----------- | --------------------------- | --------------------------- |
| Cek cepat   | `Valid(s) bool`             | `isValid(s): boolean`       |
| Parse       | `Parse(s) (T, error)`       | `parse(s): Result<T>`       |
| Normalisasi | `Format(s) (string, error)` | `format(s): Result<string>` |
| Mask        | `Mask(s) string`            | `mask(s): string`           |

Nama fungsinya mengikuti gaya tiap bahasa (`WhatsAppLink` di Go, `whatsappLink` di TypeScript). Kedua implementasi diuji dengan test vector yang sama, jadi hasilnya identik. Di TypeScript, `fake`, `zod`, dan `valibot` cuma tersedia lewat subpath.

:::note[Data contoh]
Semua nomor di situs ini dibuat dengan [`fake`](/reference/fake/). Jangan tempel data pribadi asli ke contoh, issue, atau chat AI.
:::
