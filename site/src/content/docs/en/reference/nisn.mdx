A NISN has 10 digits. No official document describes an internal structure or check digit, so NusaIndex checks length, characters, and that the number is not all zeros.

## Functions

| Go               | TypeScript        | Returns                            |
| ---------------- | ----------------- | ---------------------------------- |
| `nisn.Valid(s)`  | `nisn.isValid(s)` | Whether `s` is a well-formed NISN  |
| `nisn.Parse(s)`  | `nisn.parse(s)`   | `{ nisn }` with separators removed |
| `nisn.Format(s)` | `nisn.format(s)`  | 10 digits                          |
| `nisn.Mask(s)`   | `nisn.mask(s)`    | Last 4 digits visible              |

Accepted separators: space, `.` and `-`.

## Errors

`length`, `charset`, `serial`.
