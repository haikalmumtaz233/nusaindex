`mask` menjauhkan NIK, NPWP, nomor HP, dan nomor identitas lain dari log, layar, dan tiket layanan, misalnya untuk memenuhi prinsip minimalisasi data UU Pelindungan Data Pribadi (UU PDP).

## Fungsi

| Go                      | TypeScript        | Hasil                                                      |
| ----------------------- | ----------------- | ---------------------------------------------------------- |
| `mask.NIK(s)`           | `mask.nik(s)`     | Hanya 4 digit terakhir terlihat                            |
| `mask.NPWP(s)`          | `mask.npwp(s)`    | Hanya 4 digit terakhir terlihat                            |
| `mask.NIP(s)`           | `mask.nip(s)`     | Hanya 4 digit terakhir terlihat                            |
| `mask.NISN(s)`          | `mask.nisn(s)`    | Hanya 4 digit terakhir terlihat                            |
| `mask.Account(s)`       | `mask.account(s)` | Hanya 4 digit terakhir terlihat                            |
| `mask.Phone(s)`         | `mask.phone(s)`   | `+62` dan 3 digit terakhir terlihat                        |
| `mask.Text(s)`          | `mask.text(s)`    | Teks bebas dengan setiap deret 10 digit atau lebih di-mask |
| `mask.Redact(v)`        | `mask.redact(v)`  | Salinan objek, array, atau nilai yang sudah diredaksi      |
| `mask.NewHandler(next)` | —                 | Handler `log/slog` yang meredaksi sebelum `next`           |

Fungsi per jenis sama dengan `nik.Mask`, `phone.Mask`, dan seterusnya, dikumpulkan di satu tempat.

## Teks bebas

`Text` mencari angka yang mirip nomor identitas (10 digit atau lebih, boleh dengan pemisah umum) dan me-mask masing-masing dengan aturan jenisnya: nomor HP menyisakan `+62` dan 3 digit, lainnya 4 digit. Pemindaiannya linear dan menerima sampai 1 MiB (`MaxText` / `MAX_TEXT`); input lebih panjang gagal dengan `length`.

## Objek

`Redact` mengembalikan salinan di mana setiap string dan key melewati `Text` (string di atas 1 MiB menjadi `[redacted]`) dan setiap bilangan bulat 10 digit atau lebih di-mask. Fungsi ini tidak pernah mengubah input, tidak pernah memanggil getter (TypeScript mengembalikan `[Getter]`), melewati key `__proto__`, `constructor`, dan `prototype`, mengganti referensi melingkar dengan `[Circular]`, dan berhenti di kedalaman 32 (`[MaxDepth]`).

Di Go, `Redact` menerima nilai apa pun. Struct menjadi map dengan key nama JSON-nya (field bertag `json:"-"` dan field tak terekspor dibuang), map, slice, array, dan pointer ditelusuri, `[]byte` diperlakukan sebagai teks, dan `time.Time` dibiarkan. Nilai yang tidak bisa diperiksa, seperti fungsi dan channel, menjadi `[redacted]` alih-alih diteruskan apa adanya.

## Handler `slog` di Go

`NewHandler` membungkus `slog.Handler` apa pun dan meredaksi pesan, setiap key dan grup, serta setiap nilai string, angka, dan `slog.Any` (lewat `Redact`) sebelum record diteruskan.
