NIP 18 digit punya dua susunan:

| Jenis  | Susunan                                                                                                               | Dasar                |
| ------ | --------------------------------------------------------------------------------------------------------------------- | -------------------- |
| `pns`  | Tanggal lahir `YYYYMMDD`, TMT `YYYYMM`, digit jenis kelamin, nomor urut 3 digit                                       | Perka BKN 22/2007    |
| `pppk` | Tanggal lahir `YYYYMMDD`, tahun pengangkatan `YYYY`, perjanjian kerja ke- mulai `21`, digit jenis kelamin, nomor urut | Peraturan BKN 1/2019 |

## Fungsi

| Go              | TypeScript       | Hasil                                 |
| --------------- | ---------------- | ------------------------------------- |
| `nip.Valid(s)`  | `nip.isValid(s)` | Apakah `s` NIP yang strukturnya benar |
| `nip.Parse(s)`  | `nip.parse(s)`   | Field di bawah                        |
| `nip.Format(s)` | `nip.format(s)`  | `19881227 200809 2 553`               |
| `nip.Mask(s)`   | `nip.mask(s)`    | Hanya 4 digit terakhir terlihat       |

Pemisah yang diterima: spasi, `.`, dan `-`.

## Field hasil parse

| Field (JSON)      | Contoh       | Catatan                                                 |
| ----------------- | ------------ | ------------------------------------------------------- |
| `nip`             | 18 digit     |                                                         |
| `kind`            | `pns`        | `pns` atau `pppk`                                       |
| `birthDate`       | `1988-12-27` |                                                         |
| `appointmentDate` | `2008-09`    | `YYYY-MM` untuk PNS, `YYYY` untuk PPPK                  |
| `sex`             | `female`     | Digit `1` laki-laki, `2` perempuan                      |
| `serial`          | `553`        |                                                         |
| `agreement`       | `1`          | Hanya PPPK: perjanjian kerja ke berapa (`21` = pertama) |

## Error

`length`, `charset`, `date`, `sex`, `serial`.
