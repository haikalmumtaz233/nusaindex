Data wilayah mengikuti Kepmendagri 300.2.2-2138/2025 sebagaimana diubah 300.2.2-2430/2025. Setiap level menambah satu segmen kode:

Kode boleh ditulis dengan atau tanpa titik, spasi, atau strip (`3171`, `31.71`, `31 71`).

## Fungsi

| Go                        | TypeScript                | Hasil                                                                                                   |
| ------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------- |
| `region.Get(code)`        | `region.get(code)`        | Satu wilayah dengan kode terkini                                                                        |
| `region.Resolve(code)`    | `region.resolve(code)`    | Seperti `Get`, tetapi mengikuti kode yang berubah karena pemekaran Kalimantan Utara 2012 dan Papua 2022 |
| `region.Children(code)`   | `region.children(code)`   | Anak langsung; `""` menampilkan semua provinsi                                                          |
| `region.Search(q, opts)`  | `region.search(q, opts)`  | Wilayah yang namanya cocok dengan `q`, terbaik dulu                                                     |
| `region.ByPlate(code)`    | `region.byPlate(code)`    | Kabupaten/kota yang memakai kode plat seperti `DR`                                                      |
| `region.ByAreaCode(code)` | `region.byAreaCode(code)` | Provinsi atau kabupaten/kota di balik kode area telepon                                                 |
| `region.FromNIK(nik)`     | `region.fromNik(nik)`     | Nama provinsi, kabupaten/kota, dan kecamatan dari NIK                                                   |

Di TypeScript semua fungsi `async`: data kecamatan dan desa dipecah per provinsi dan baru dimuat saat dibutuhkan. Indeks provinsi, kabupaten/kota, alias, plat, dan kode area kurang dari 16 KB gzip. Di Go, data dimuat sekali saat pertama dipakai (sekitar 10 ms).

Chunk per provinsi memakai `import()` dinamis. Vite, webpack, Rollup, dan esbuild dengan `splitting: true` menghasilkannya sebagai file terpisah. Bundler yang menggabungkan import dinamis akan memasukkan semua provinsi ke satu file (sekitar 500 KB gzip), jadi aktifkan code splitting untuk build browser.

### Opsi pencarian

| Go `SearchOptions` | TypeScript | Arti                                                           |
| ------------------ | ---------- | -------------------------------------------------------------- |
| `Level`            | `level`    | Hanya satu level: `province`, `regency`, `district`, `village` |
| `Within`           | `within`   | Hanya turunan kode ini                                         |
| `Limit`            | `limit`    | 1 sampai 100, default 10                                       |

Pencocokan tidak membedakan huruf besar/kecil dan mengabaikan awalan `Kabupaten`/`Kota`. Nama yang persis sama muncul pertama, lalu awalan, awal kata, kemudian potongan kata mana pun. Query dibatasi 256 karakter.

Mencari kecamatan atau desa tanpa `within` membaca semua provinsi. Di browser, isi `within` agar hanya satu provinsi yang dimuat.

### `Place` (dari NIK)

| Field        | Catatan                                                                                   |
| ------------ | ----------------------------------------------------------------------------------------- |
| `province`   | Selalu ada                                                                                |
| `regency`    | Ada jika kabupaten/kotanya masih ada                                                      |
| `district`   | Ada jika kecamatannya masih ada                                                           |
| `historical` | `true` jika NIK memakai kode sebelum pemekaran; nama yang dikembalikan tetap nama terkini |

## Error

`length`, `charset`, `unknown` (kode strukturnya benar tetapi tidak ada), `options`.
