## Aman sejak awal

- **Offline.** Tanpa panggilan jaringan, log, atau telemetri. Input tidak pernah keluar dari proses Anda.
- **Bisa ditelusuri.** Setiap dataset menyebut regulasi dan dokumen sumbernya di [`data/manifest.json`](/id/project/data-sources/).
- **Tidak resmi.** Tidak berafiliasi dengan Dukcapil, DJP, Komdigi, Polri, Bank Indonesia, atau instansi pemerintah mana pun. Valid berarti **strukturnya benar**, bukan berarti nomornya asli atau dimiliki seseorang.
